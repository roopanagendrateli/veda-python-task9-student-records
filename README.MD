# Task 9 - Student Records System

## Description
A Python program that stores student names and marks and allows users to manage student records.

## Features
- Store student names and marks using lists
- Display all student records
- Search for a student by name
- Sort students by marks from lowest to highest
- Find the highest and lowest scores
- Validate user input

## Concepts Practiced
- Python lists
- Functions
- Loops and conditional statements
- Searching and sorting
- Exception handling
- User input validation

## How to Run
```bash
python student_records.py
```

## Sample Records
- Anu: 85 marks
- Ravi: 92 marks
- Priya: 67 marks

## Expected Results
- Highest score: Ravi with 92 marks
- Lowest score: Priya with 67 marks
